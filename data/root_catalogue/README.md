# Disclosed root catalogue

This directory contains the immutable disclosed source catalogue used in the companion manuscripts:

- `Planetary_Coincidences_STATISTICAL_VALIDATION_EN_REVISED.xlsx` — original workbook with root tables, methodology, statistical test, sensitivity analysis, and disclosure sheets.
- `roots_1_8.csv`, `roots_3_6.csv`, `roots_7_9.csv` — full CSV exports of the corresponding worksheets, including historical annotation columns and a computed `jd_tdb` field used by the independent CSV validation script.

Generated roots from the reconstructed NASA/JPL Horizons pipeline are written to `outputs/generated_roots/` and must never overwrite this directory.
