# Repository constitution

1. Released results must be reproducible from version-controlled code, configuration, and documented inputs.
2. Generated outputs are never edited manually.
3. Scientific parameters are expressed in configuration files whenever the engine supports them.
4. The validated baseline is preserved; experiments use separate named configurations and output namespaces.
5. Validation precedes release.
6. Material discrepancies and limitations are documented.
7. Source data, generated outputs, and interpretive provenance remain clearly separated.
8. Every stable release is versioned, archived, and citable.
