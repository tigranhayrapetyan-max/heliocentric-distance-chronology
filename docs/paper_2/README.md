# Paper 2 — Post-Flood Genealogy as a Compressed Founding Formula

**Working publication title**

*Post-Flood Genealogy as a Compressed Founding Formula: A Chronological, Textual, and Archaeological Study of the Gomer–Tiras–Togarmah–Hayk Sequence*

## Status

The journal submission package was finalized on 7 August 2026. The manuscript files themselves are intentionally not mirrored in this public repository before publication. This directory contains the reproducibility-facing materials that can be disclosed independently of the unpublished manuscript.

## Included here

- `Supplementary_Table_S1_Principal_Nodes.csv` — machine-readable provenance table for the astronomical nodes used in the paper.
- `SUBMISSION_PACKAGE_MANIFEST.txt` — archival inventory of the finalized submission package.

## Computational relationship to the main repository

Paper 2 does not perform a new global astronomical search. It interprets a fixed set of previously generated astronomical nodes and keeps their subsequent historical assignments explicitly traceable in Supplementary Table S1.

The underlying root-generation workflow is supplied by the repository's validated Heliocentric Distance Chronology implementation and its archived Zenodo release.

## Scope statement

The proposed dates are treated as falsifiable candidate correspondences, not as an established absolute chronology of the early third millennium BCE.
