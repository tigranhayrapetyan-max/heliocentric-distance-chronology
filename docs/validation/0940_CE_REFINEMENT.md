# 0940 CE targeted refinement

A targeted high-resolution JPL Horizons refinement was performed for the single 1–8 timestamp that exceeded the legacy comparison tolerance.

The refined root converged to approximately **0940-02-15 01:09:15 TDB**, with a numerical residual effectively equal to zero. It differed from the legacy catalogue timestamp by approximately **166.5 seconds**, while agreeing with the regenerated root to within approximately one second.

This is documented as a legacy timestamp discrepancy, not as a different astronomical event. The executable refinement procedure is preserved in `tools/validation/refine_940_horizons_v2.py`.
