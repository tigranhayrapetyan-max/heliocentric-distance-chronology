# H2/H3 HISTORICAL MATCH RULE — CORRECTION V2

## Correct rule
- H2 = corrected 7–9 root catalogue.
- H3 = corrected 3–6 root catalogue.
- For historical testing, an H2 or H3 event is a match only if the astronomical root calendar day is the same calendar day as a historical event with an independently sourced exact day.
- H1 membership is not required for this historical H2/H3 match.
- No ±day tolerance.
- Year-only, interval, approximate, century, and source-disagreement historical dates cannot be used in this same-day H2/H3 test.
- H4 remains a separate astronomical construct (H1 containing H2/H3 roots); it must not be substituted for the direct historical same-day rule.
