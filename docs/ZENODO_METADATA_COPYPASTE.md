**Description:**
This release discloses the original root workbook, full CSV root catalogues, the original and independently reconstructed circular time-shift validation workflows, a clean-room NASA/JPL Horizons root-generation implementation, fixed parameters, provenance tables, and verified statistical outputs supporting two companion studies of Armenian historical and mythological chronology. The disclosed catalogue contains 7,863 1-8 roots, 447 3-6 roots, and 42 7-9 roots. The conditional circular-shift proportion (`0.001607873066...`) and fixed-seed Monte Carlo result (`1649/1,000,000`) were reproduced from both the workbook and CSV exports. The Horizons root generator awaits network execution, the mandatory 139 BCE control validation, full-catalogue regeneration, and root-by-root comparison; the release is therefore versioned 0.9.1 rather than 1.0.0.
